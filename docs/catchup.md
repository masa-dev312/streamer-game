# 逆転ルールの検討(2026-10-14)

masaki さんの感想は次のとおりです。「トップを邪魔する手段が少ないので、序盤に差が開くとつまらない。逆転できるルールがほしい。ただし理不尽な逆転は冷める」

検討には、Claude が想定した次の立場が参加しました(実在の人物ではありません)。

- ボードゲームデザイナー(レースゲームの追い上げ要素が専門)
- 配信と盛り上がりの専門家
- プレイヤー代表(先頭を走りがちな上級者と、置いていかれがちな初心者の2つの声)
- 数値検証(ボット同士の自動対戦で比べる)

## 1. 今のルールで何が起きているか

ボット同士で3000試合ずつ遊ばせて測りました。

| | 2人 | 3人 | 4人 |
|---|---|---|---|
| 3ラウンド目の先頭が勝つ率(全員が同じ強さなら) | 77%(50%) | 60%(33%) | 50%(25%) |
| 先頭が伏せマスを踏む率 / それ以外の人 | 22% / 46% | 29% / 48% | 26% / 45% |
| 先頭と最下位の差(3R目→終了時) | 8.7→14.0 | 11.0→16.1 | 10.5→16.5 |
| 先頭交代(1試合あたり) | 0.8回 | 1.3回 | 1.5回 |

**原因(3つの立場で一致)**

- 伏せマスの位置は「?」で見えます。先頭はサイコロ2個から目を選べるので、伏せマスを避けられます。両方の目が伏せマスに当たったときしか踏みません。
- 後ろの人は、先頭を狙ったワナも含め、自分より前にある伏せマスを全部通ります。
- 最下位の「手札+1」はほとんど効いていません。置ける数の上限(4人なら1ラウンド1個)が変わらないためです。

## 2. 「冷める逆転」と「納得できる逆転」(配信とプレイヤー代表の意見)

- **冷める逆転**
  - 理由の見えない運で、1回で全部ひっくり返るもの
  - 何もしていないのに起きるもの
  - 位置の入れ替えのように、序盤の頑張りが無意味になるもの
- **納得できる逆転**
  - 条件が画面に予告されているもの
  - だれかが仕掛けを選んだ結果として起きるもの
  - 1回では詰めきれず、2〜3回の積み重ねで縮むもの
  - 先頭側にも打つ手が残っているもの

## 3. 比べた案(自動対戦、各3000試合)

数値は「3ラウンド目の先頭が勝つ率」(2人 / 3人 / 4人)です。

| 案 | 中身 | 結果 | 判断 |
|---|---|---|---|
| なし | 今のルール | 77 / 60 / 50% | |
| 足音 | 先頭のサイコロ1個目を、仕掛けの前に公開する | 78 / 62 / 50% | **見送り**。先頭はもう1個の目で避けるだけで、効果が出なかった |
| 重い荷物 | 先頭が2位より6マス以上前なら、サイコロ1個だけ(目を選べない) | 72 / 54 / 48% | 採用。避けられる原因に直接効く |
| 賞金首 | 先頭にワナを当てると、2位との差3ごとに+1マス(最大+3) | 74 / 57 / 49% | 採用。単独の効果は小さいが、狙う理由が画面に出る |
| 最下位の置ける数+1 | 最下位が先頭から6マス以上遅れていたら、そのラウンドは置ける数+1 | 69 / 56 / 45% | 採用。効いていなかったボーナスを置き換える |
| 追い上げの一手 | 先頭から10マス以上遅れたら、サイコロ2個の合計でも進める | 70 / 51 / 42% | 採用。遅れた人の手番が楽しくなる |
| **4つ全部(採用)** | 上の4つ | **58 / 44 / 35%** | |
| 重い荷物を4マスからにした場合 | | 55 / 44 / 34% | 先頭が目を選べない場面が増える。上級者が冷めやすいので6マスにした |

**採用案の、そのほかの数値(今のルール → 採用案)**

- 先頭と最下位の差(終了時): 2人 14.0→6.8、3人 16.1→10.0、4人 16.5→10.9マス
- 1位と2位の差が3マス以内で終わる試合: 2人 11→25%、3人 25→43%、4人 25→43%
- 先頭交代: 2人 0.8→1.4回、4人 1.5→2.1回
- 3ラウンド目の先頭が勝つ率は、どの人数でも「全員が同じ強さ」の値より高いままです。先に出た価値は残ります。

## 4. 採用したルール

すべて「差が開いたときだけ」働きます。配信画面では、順位の欄に札(賞金+N / 重い荷物 / 置ける+1 / 追い上げ)が出て、だれに何が起きているか分かります。

1. **賞金首**: 先頭が2位より3マス以上前にいると、先頭のコマに「賞」の印が付きます。先頭にワナを当てた人は、通常の前進に加えて「差÷3(最大3)」マス進みます。表彰に「大物食い」を加えました。
2. **重い荷物**: 先頭が2位より6マス以上前にいると、先頭のサイコロは1個だけになります(目を選べない)。
3. **最下位ボーナス**: 最下位が先頭から6マス以上遅れていると、そのラウンドは置ける数が1つ多くなります。
4. **追い上げの一手**: 先頭から10マス以上遅れている人は、サイコロ2個の合計でも進めます。行き先が3つ光ります。

先頭に残る打つ手は次のとおりです。

- 差が6マス未満なら、目を選んで避けられる
- 自分の前に宝箱を置いて、通り道をふさげる
- 後ろの人にワナを置いて足止めできる

位置の入れ替えや、ランダムな大逆転イベントは入れていません。

## 5. 気をつけていること・次に見ること

- ボットは人間ほど上手に伏せマスを避けません。人間の先頭は、表の数値よりも逃げやすいと推測しています。重い荷物は、人間どうしで遊ぶとこの表より効くはずです。実際に遊んだ感想で調整します。
- 「わざと遅れて追い上げを使う」作戦が成り立たないかは、これから確認します。追い上げは10マス以上遅れていることが条件で、そこまで遅れると勝つ率は低いと推測しています。
- 数値はすべて `src/rules.js` の `TUNE`(heavyGap / bountyDiv / bountyMax / trailerPlaceGap / sumGap)で変えられます。null にするとその仕組みが止まります。
