よけゲー型の旧案へのレビューは プロジェクトの共有フォルダ(streamer-game/旧案/)にあります。

## 2. 想定ユーザー(配信者/常連視聴者/初見視聴者)
主な声: ターン制で雑談しながら遊べそう(配信者)。`!wana 3` はスマホで入力モードの切り替えが多い(初見)。マス番号が付け直されると遅延で狙いがずれる(初見)。大人数で同じマスに仕掛けたとき誰の名前が出るか不明(常連)。対決中に視聴者がやることがない(常連)。宝箱のコマンドがない、ワナとモンスターの違いが不明(常連)。ボットのワナでは名前を呼べない(配信者)。

v1.1 での扱い: 短い書き方・「!」なし・全角も受付(3.7)、マス番号は絶対番号(3.7)、代表1名+他N人(3.8)、対決の予想(3.6)、宝箱コマンドと仕掛けの定義(3.4, 3.7)、カウントダウンと受付表示(3.6, 3.7)、ランキングと振り返り(3.9)、ターン数・秒数の設定(3.1)をすべて採用。ボットで名前を呼べない点は、ボットだと分かる見た目にすることのみ対応し、盛り上げ方は試作で検討。

## 3. セキュリティ専門家
- **引き継ぎの漏れ**: v1.0 では旧案の対策の一部(大量コマンド対策、APIキーの扱い、Unicode、OBS、CDN/CSP、規約、プライバシー)が抜けていた → 旧案の表をすべて6.1に戻した
- **新案特有のリスク**: 名前がマスに残り続ける、マス番号の不正な入力、1マス集中での詰み、複数アカウントの妨害、締め切り後の駆け込み、ランキング改ざん、ボットの名前 → すべて6.2に対策つきで反映
