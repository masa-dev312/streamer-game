# ワナしかけダンジョン 見た目とUXの見直し(2026-10-14)

masaki さんの感想「画面が見難い。映えないので配信者に使ってもらえない。楽しさが伝わらない」を受けて、4つの立場で今の画面(PC 1360x860 とスマホ 390x844 のスクリーンショット)とコードを見直しました。
ここでの「専門家」は Claude が想定した立場で、実在の人物ではありません。

## 4つの立場が一致した問題

| 問題 | 根拠(今の画面・コード) | 指摘した立場 |
|---|---|---|
| 主役が分からない | 一番目立つのはオレンジの「表示モード」バッジ。手番・順位・伏せ札が埋もれている | 配信・デザイン・ゲーム |
| 盤面が単調で空きが多い | 同じ灰色の四角が40個。右下に4マス分の空白。マス番号は11pxで背景とほぼ同じ色 | 配信・デザイン |
| コマが小さい | 半径11pxに1文字。手番は2pxの白いふちだけ | 全員 |
| 見せ場が文字の箱だけ | ワナ・横取りは中央に文字の箱が出るだけで、事件のマスを隠す。コマは瞬間移動するので「戻る・進む」の逆転が見えない | 配信・ゲーム・開発 |
| 順位が分からない | 下の帯は「23マス目」の数字だけ | 配信・ゲーム |
| スマホで読めない | 配信画面が約0.37倍に縮み、11pxの文字は約4pxになる | 全員 |
| 結果が配信に映らない | 結果と表彰は Canvas の外の文字の一覧 | 配信・デザイン |
| 色の意味がぶつかる | プレイヤーの赤とワナの赤、置ける枠の緑とプレイヤーの緑が同じ | デザイン |
| 文字がにじむ | 高解像度の画面に対応していない(960x540 を拡大表示) | 開発 |

## 決めたこと

| 項目 | 採用した案 | 失うもの・リスク |
|---|---|---|
| 盤面 | 外周を一周するダンジョンの盤にする。中央の広い空間を「舞台」にして、順位・サイコロ・事件の告知を出す | 1マスが小さくなる(96x74 → 62x64)。そのかわり文字を減らし、コマと仕掛けは大きく描く |
| 雰囲気 | 暗い石畳とたいまつの光の配色にする。ゴールは金の扉にする | 暗い配信画面の中では沈むおそれがある。縁を明るくして補う |
| 色 | プレイヤーは青・緑・桃・白にする。赤はワナ、黄は宝箱だけに使う | 「赤の人」という呼び方はできなくなる |
| コマ | 半径17pxで白いふちを付ける。手番のコマは光る輪と矢印で示す | 同じマスに4人いると重なる |
| 動き | コマが1マスずつ跳ねて進む。ワナでは踏んだ人が戻り、仕掛けた人が進む動きを同時に見せる | 1手が1〜2秒長くなる。早送りでは短くする |
| 見せ場 | 事件のマスで爆発・飛び散り・画面の揺れを出す。告知は舞台に大きな一語で出す。強さは3段階(大: ワナ・自爆・横取り/中: 宝箱・いたずら/小: ニアミス・見せかけ) | 小さい事件はより地味になる。動きを減らす設定の端末では揺れを止める |
| 順位 | 舞台に順位順のレース棒を常に出す(ゴールまでの残りマス) | 盤面と情報が重なる |
| 来る来る | 行き先の伏せマスを大きく脈打たせ、舞台にも「○○が伏せマスへ…」と出す | なし |
| 置く操作 | 置けるマスを、狙う相手の色で塗る | 色が増える |
| サイコロ | 舞台に目の数の点がある大きなサイコロ2個を出す | なし |
| 結果 | 舞台に表彰台(1〜3位)と賞を出す。詳しい一覧は手元画面に出す | 長いリプレイは手元画面だけになる |
| タイトル | 盤面の舞台にロゴを描く。モードの選択は短くし、説明は選んだものだけ出す | なし |
| スマホ | 縦長の画面では盤面を縦向き(横8×縦15マス)で描く。操作パネルは画面の下に固定する | 配信用の16:9とは別の見た目になる(スマホで配信を取り込むことは想定しない) |
| にじみ | 画面の解像度に合わせて描く | なし |

## 意見が分かれて、見送ったこと

- **伏せ札のふちを置いた人の色にする**(配信の立場の案): 「隠す」モードでは、だれが置いたかも伏せている情報です。色で分かると読み合いの性質が変わるため、見送りました。かわりに、近づいた伏せマスを脈打たせます。
- **練習ラウンド**(ゲームの立場の案): 最初の1分の体験には効きます。ただし慣れた配信者にはじゃまで、飛ばす仕組みが要るため、次の段階にします。今回は、最初のラウンドだけ舞台に遊び方を出します。
- **配信画面だけの別ウィンドウ**(開発の立場の案): OBS に配信画面だけを取り込めて、答えが配信側に届かない良さがあります。ただし、2つのウィンドウで状態を同期する作りが必要なため、次の段階にします。
- **専用フォント**: 外部フォントは使えません(セキュリティ設定)。リポジトリにフォントを置く方法はありますが、容量とライセンスの確認が要るため見送りました。

## 変えないこと

- ルールと数値(rules.js の TUNE)。ボット同士の自動対戦で、結果が変わっていないことを確認します。
- 表示モード(4種類)と、見せかけを配信画面でワナと同じ見た目にすること。
