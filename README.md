# ワナしかけダンジョン(仮題)

招待された2〜4人の参加者が、おたがいの行く先にワナや宝箱を伏せて置きながら進む、すごろくレースのブラウザゲームです。配信者どうしのコラボ配信で遊ぶことを主に想定しています。視聴者はゲームに参加しないので、荒らしやアンチの影響を受けません。

現在は試作版です。ボットを相手に1人で遊べます(通信対戦はまだありません)。

## 試作の遊び方
- ブラウザで `index.html` を開きます。JavaScript のモジュールを使うので、ファイルを直接開くのではなく、Web サーバー経由で開いてください(例: `npx http-server -p 8123` を実行して http://127.0.0.1:8123/ を開く)。GitHub Pages で公開した場合は、そのURLで遊べます。
- 表示名、ボットの人数(1〜3人)、表示モード(隠す/自分の仕掛けを表示/ボットの仕掛けだけ表示/全部表示)を選んで始めます。
- 左が配信画面(OBS に取り込む想定)、右が手元画面(配信に映さない想定)です。手札の操作は手元画面で行います。
- 配信画面は、ダンジョンの外周を一周する盤面です。内側の「舞台」に順位・サイコロ・事件の告知が出ます。
- スマホを縦に持つと盤面が縦長になり、操作パネルは盤面の内側に重なります。
- 差が開いたときだけ働く逆転の仕組み(賞金首・重い荷物・最下位ボーナス・追い上げの一手)があります。
- 数値(ゴールまでのマス数、戻る・進むマス数、山札の内訳など)は `src/rules.js` の `TUNE` にまとめています。

## 確認
- `node tests/balance.mjs 3000`: 逆転のしやすさ(3ラウンド目の先頭が勝つ率、先頭交代の回数など)を測ります。
- `node tests/catchup-compare.mjs 2000`: 逆転の仕組みを1つずつ入れた場合と、全部入れた場合を比べます。
- `node tests/sim.mjs 2000`: ボットだけで多数回遊ばせ、ゲームが必ず終わること、位置や仕掛けが範囲外にならないこと、表示名の安全化を確かめます。人数・モードごとの平均ラウンド数や勝率も表示します。
